# 06_CHECKLIST_DE_VALIDACAO_DO_AGENTE — v2.2.1

## OBJETIVO

Verificar se a execução do Agente Editorial respeitou o Protocolo Mestre e produziu um resultado seguro para avançar à próxima etapa.

Utilizar este checklist após cada lote executado no Work.

---

# A. VALIDAÇÃO DOS ARQUIVOS

[ ] O arquivo original permaneceu intacto.

[ ] O agente utilizou o PERFIL_DO_AUTOR.

[ ] O agente utilizou as REGRAS_EDITORIAIS.

[ ] O agente seguiu o PROTOCOLO_MESTRE.

[ ] Os arquivos de saída possuem nomes claros e versões distintas.

[ ] Nenhuma versão editada foi tratada como original.

---

# B. DIAGNÓSTICO E MAPEAMENTO

[ ] O tema central foi corretamente identificado.

[ ] Os principais subtemas foram encontrados.

[ ] Os argumentos do autor foram mapeados.

[ ] Exemplos e testemunhos foram identificados.

[ ] Referências importantes foram registradas.

[ ] Repetições foram identificadas sem serem automaticamente consideradas descartáveis.

[ ] Digressões foram identificadas.

[ ] O grau de oralidade foi corretamente percebido.

[ ] A voz observada no original foi comparada com o PERFIL_DO_AUTOR.

[ ] Contradições ou inconsistências foram sinalizadas.

---

# C. TRANSFORMAÇÃO DA ORALIDADE

Pergunta principal:

**O resultado parece um livro escrito pelo autor ou ainda parece uma transcrição?**

[ ] Comandos de palco foram removidos ou adaptados.

[ ] Pedidos de aplausos foram removidos quando irrelevantes.

[ ] Respostas coletivas foram reduzidas quando necessário.

[ ] Hesitações foram eliminadas.

[ ] Frases fragmentadas foram transformadas em escrita natural.

[ ] Repetições puramente orais foram reduzidas.

[ ] Perguntas retóricas importantes foram preservadas.

[ ] Humor característico foi preservado quando compreensível.

[ ] Exemplos pessoais permaneceram.

[ ] Tom e personalidade do autor continuam reconhecíveis.

[ ] A oralidade foi efetivamente transformada em linguagem escrita profissional.

[ ] O Teste de Origem foi aplicado.

[ ] O Teste de Origem foi APROVADO.

[ ] O texto destinado ao livro não utiliza voz de relator.

[ ] Não permanecem construções como “o autor afirma”, “o autor explica”, “o autor recorda”, “segundo o autor” ou equivalentes, salvo quando editorialmente indispensáveis.

[ ] Quando o original utiliza primeira pessoa, a voz autoral foi preservada ou reconstruída adequadamente.

Pergunta adicional:

**Este trecho está escrito como texto do próprio autor ou como alguém relatando aquilo que o autor disse?**

Se parecer relatório:

**NÃO APROVAR O TRECHO.**

Reescrever somente a forma, sem alterar o conteúdo.

# F. EXPANSÃO INTERPRETATIVA E TESTE DE RESSALVA EDITORIAL

Verificar especialmente construções como:

- “é importante lembrar que...”
- “isso não significa que...”
- “não se trata de...”
- “é importante esclarecer que...”
- “devemos compreender também...”
- “isso não quer dizer que...”
- “não ignoro...”
- “é claro que isso não elimina...”
- “não devemos interpretar isso como...”
- “é preciso considerar também...”
- “historicamente...”
- “teologicamente...”
- “em outras palavras...”

Essas construções não são automaticamente erradas.

Porém, precisam estar sustentadas pelo conteúdo original.

[ ] Toda ressalva, qualificação ou frase conciliatória foi comparada com a fonte.

[ ] Toda expansão existente possui base no texto original.

[ ] Nenhuma ressalva foi criada apenas para tornar a argumentação mais equilibrada.

[ ] Nenhuma ressalva foi criada para suavizar a posição do autor.

[ ] Nenhuma ressalva foi criada para proteger o autor de possíveis interpretações.

[ ] Nenhuma contextualização externa foi acrescentada.

[ ] Nenhuma explicação foi inserida apenas porque parecia útil, prudente ou correta.

[ ] Nenhuma expansão classificada como D permaneceu no texto.

Pergunta obrigatória:

**Esta ressalva está sustentada diretamente pelo conteúdo original?**

Se NÃO:

classificar como:

**D — EXPANSÃO INTERPRETATIVA**

e remover.

Pergunta adicional:

**Estou acrescentando esta frase porque o autor realmente apresentou essa ideia ou porque considero que o texto ficaria mais equilibrado, seguro, educado ou completo?**

Se a razão for editorial e não autoral:

**REMOVER.**

# G. RETENÇÃO SUBSTANTIVA

Registrar por bloco:

Original: __________ palavras

Transformado: __________ palavras

Retenção aproximada: __________ %

O percentual é um detector de risco.

Não é meta editorial.

## Faixas

### 60% ou mais

[ ] Auditoria normal realizada.

---

### 45% a 59%

[ ] Alerta amarelo identificado.

[ ] A redução foi examinada.

[ ] Confirmado que a redução decorre principalmente de oralidade, repetição, comandos, liturgia ou redundância.

[ ] Argumentos, exemplos, testemunhos e aplicações permanecem representados.

---

### 30% a 44%

[ ] Alerta vermelho identificado.

[ ] Auditoria extraordinária de cobertura substantiva realizada.

[ ] O bloco foi comparado novamente com o original antes de aprovação.

---

### Menos de 30%

[ ] O bloco não foi aprovado automaticamente.

[ ] Houve justificativa editorial excepcional documentada ou transformação refeita.

---

## Cobertura substantiva

Antes de aprovar cada bloco:

[ ] Tese preservada.

[ ] Argumentos preservados.

[ ] Exemplos preservados.

[ ] Testemunhos preservados.

[ ] Analogias preservadas.

[ ] Aplicações preservadas.

[ ] Referências importantes preservadas.

[ ] Conclusões preservadas.

[ ] Posicionamentos preservados.

[ ] Intensidade autoral adequadamente representada.

[ ] Nenhuma expansão interpretativa criada.

[ ] O percentual de retenção não foi usado como meta artificial de tamanho.

## REGRA DE APROVAÇÃO

Somente aprovar se:

**Fidelidade = 10**

**Ausência de invenções = 10**
